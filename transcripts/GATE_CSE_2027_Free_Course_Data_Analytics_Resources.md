## 4. Step-by-Step Preparation Strategy

### 🔵 Step 1 — Build Fundamentals (Video Watching)

- Watch the speaker's **121-hour one-shot series** covering every GATE CSE subject
- Subjects: OS, DS, Digital Architecture, TOC, Algorithm, Discrete, Networks, DBMS
- All available **free on YouTube**
- **Watch with full focus** — pause, rewind, solve examples yourself
- **Timeline**: ~40-45 days to complete all videos
- After this, you should be at **25-35 marks level**

> 🎯 **Key Advice**: Don't rush. Understand every concept. Watch like it's your first time.

### 🟢 Step 2 — Problem Solving (Practice Questions)

- **3000 Previous Year GATE Questions** — available FREE on the learning platform
- Solve in **increasing order of difficulty**
- Start with PYQs, then move to practice questions
- After PYQs, move to **300 Practice Questions** (harder, 5-7 min each)
- With consistent solving → **55-65 marks range**
- For **75+ marks**, you need more problem solving

> 🎯 **Key Advice**: Without problem solving, nothing works. Period.

## 6. Data Analytics — Complete Roadmap

### What is Data Analytics?

Data Analytics is the process of examining datasets to draw conclusions and support business decisions. It combines **statistics, programming, and domain knowledge** to turn raw data into actionable insights.

### Core Skills You Need

| Skill | Tool | Priority | Why |
|-------|------|----------|-----|
| Excel | Spreadsheets | Medium | Quick analysis, everyone uses it |
| SQL | MySQL, PostgreSQL | **HIGH** | Every analyst job requires it |
| Statistics | Math | **HIGH** | Validates findings, defends decisions |
| Python | Pandas, NumPy | **HIGH** | Handles large datasets, automation |
| Data Visualization | Power BI / Tableau | **HIGH** | Communicates insights to stakeholders |
| Data Storytelling | Communication | Medium | Translates numbers to business action |
| ETL & Pipelines | Airflow, dbt | Lower | Advanced — learn after getting hired |

## 7. DA Syllabus (All Modules)

### Module 1: Introduction to Data Analytics
- What is Data Analysis? Advantages of data analysis and visualization
- Four types of analytics (Descriptive, Diagnostic, Predictive, Prescriptive)
- CRISP-DM framework
- Data preparation, common data problems, analytics tools

### Module 2: Excel for Data Analysis
- Data cleaning, preparation, formatting
- Power Query, Pivot Tables
- Formulas, conditional formatting, VLOOKUP, INDEX-MATCH
- Dashboards, KPI reporting

### Module 3: SQL for Data Analysis
- SELECT, WHERE, GROUP BY, HAVING
- JOINs (INNER, LEFT, RIGHT, FULL OUTER, SELF, CROSS)
- Window functions (RANK, ROW_NUMBER, moving averages)
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- Subqueries, CTEs, Views
- Indexing, data types

### Module 4: Statistics and Probability
- Descriptive statistics (mean, median, mode, std dev, variance)
- Probability fundamentals, distributions
- Sampling techniques
- Hypothesis testing (T-tests, Chi-square, ANOVA)
- Correlation and Regression
- Confidence intervals, A/B testing

### Module 5: Python for Data Analysis
- Python fundamentals (variables, loops, functions, data structures)
- NumPy (arrays, mathematical operations, broadcasting)
- Pandas (Series, DataFrames, data cleaning, grouping, merging)
- Matplotlib & Seaborn (visualization — bar, line, scatter, heatmap)
- Data automation scripts
- Jupyter Notebook

### Module 6: Data Visualization & BI
- Power BI fundamentals (data modeling, DAX, dashboards, KPIs)
- Tableau fundamentals (worksheets, dashboards, stories)
- Data storytelling principles
- Choosing right chart types
- Interactive reports and filters

### Module 7: Data Cleaning & Preparation
- Handling missing values, outliers
- Data transformation, type conversion
- Feature engineering
- Data quality assessment

### Module 8: ETL & Modern Data Stack
- ETL vs ELT processes
- Apache Airflow, dbt
- Data Warehousing (Star Schema, Fact/Dimension)
- Cloud platforms (AWS, GCP)

### Module 9: AI-Assisted Analytics
- ChatGPT for SQL generation, Python code, insights
- Microsoft Copilot, Gemini, Claude for analytics
- Prompt engineering for data tasks

### Module 10: Capstone Project
- End-to-end analytics workflow
- Real dataset → Clean → Analyze → Visualize → Report
- Portfolio piece for interviews
